# 연애 MBTI 테스트 웹앱 (love-test)

3가지 모드(조선시대, 카톡 플러팅, 연애 흑역사)와 4단계 정밀도(12/24/36/48문항), 그리고 구글 애드센스 승인 필수 요건이 완비된 Next.js 16 + TypeScript 모던 웹 애플리케이션입니다.

- **GitHub 저장소**: [https://github.com/chocg2000/love-test](https://github.com/chocg2000/love-test) (`main` 브랜치에 최신 코드 푸시 완료)
- **기술 스택**: Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS 4
- **핵심 기능**:
  1. **3가지 테마**: 👑 조선시대 내 연애 신분, 💬 소개팅 카톡 플러팅, 🤦‍♂️ 나의 연애 흑역사
  2. **4단계 정밀도**: ⚡하(12문항/1분), 🎯중(24문항/3분), 🔍상(36문항/5분), 👑최상(48문항/8분)
  3. **수익화 설계**: 전면 광고 슬롯(3초 분석), 상단 배너 슬롯, 쿠팡 파트너스 추천 아이템, 카카오톡/링크 공유
  4. **구글 애드센스 통과 규격**: 개인정보처리방침(`/privacy`), 이용약관(`/terms`), MBTI 연애 백과사전(`/guide`), `robots.txt`, `sitemap.xml`

## 🚀 Vercel 원클릭 무료 배포 방법

이미 GitHub 저장소(`chocg2000/love-test`)에 최신 코드가 모두 올라가 있으므로 Vercel에서 클릭 몇 번이면 배포됩니다:

1. [Vercel 대시보드](https://vercel.com/dashboard)에 접속합니다.
2. 우측 상단의 **"Add New..."** → **"Project"**를 클릭합니다.
3. 목록에서 **`love-test`** 저장소를 찾아 **"Import"**를 누릅니다.
4. Framework Preset이 **Next.js**로 자동 인식되어 있으므로, 설정 변경 없이 맨 아래 **"Deploy"** 버튼을 누릅니다.
5. 약 30초 후 `https://love-test-***.vercel.app` 형태의 전 세계 접속 가능한 주소가 발급됩니다!
6. 추후 개인 도메인을 구매하시면 Vercel 프로젝트 Settings → Domains에서 도메인만 연결해 주시면 됩니다.
